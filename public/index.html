      Projects are saved in this browser. Connect GitHub under Publish to keep a copy online and put sites on the web.

      Publish

      Connect GitHub to commit this project to a repository and put it online with GitHub Pages, for free.

      You'll go to GitHub, it asks if you allow Pip Playground to use your repositories, and then you come straight back here.

      Use a token instead
      1. Open github.com/settings/personal-access-tokens/new.
      2. Under Repository access, choose All repositories.
      3. Under Permissions, set Administration, Contents and Pages to Read and write.
      4. Generate the token and paste it here.

      Your GitHub access stays in this browser only and is sent to nobody but GitHub.
